## 💡 Sobre o projeto

A **JOVI AI Camera Experience** é um protótipo web *mobile-first* que apresenta uma nova proposta para a experiência fotográfica em smartphones: mais **intuitiva, inteligente e personalizada**.

Nossa ideia vai além de capturar imagens. Queremos que a câmera acompanhe as necessidades do usuário, oferecendo novas possibilidades para aprender, criar, explorar e eternizar momentos.

### ✨ O grande diferencial: Meu JOVI

O **Meu JOVI** é o centro da nossa proposta: uma identidade personalizada que reúne preferências de filtros, gestos, configurações e estilos fotográficos.

Na visão futura do produto, essas preferências poderão acompanhar o usuário entre smartphones JOVI compatíveis, permitindo que sua experiência continue mesmo após a troca de aparelho.

> **O smartphone muda. Sua experiência continua.**

## 🚀 Como executar o projeto

**Pré-requisitos:** Node.js e npm instalados.

Clone o repositório e execute os comandos:

```bash
git clone https://github.com/AlexIshikawa/jovi-app.git
cd jovi-app
npm install
npm run build
npm run dev
```

Acesse no navegador:

**http://localhost:5500/**

> Para uma melhor experiência, utilize a visualização mobile ou o modo responsivo do navegador.

## 🔮 Protótipo e evolução futura

Este é um **projeto acadêmico demonstrativo**, desenvolvido para apresentar interfaces, navegação e possibilidades de inovação.

As funcionalidades avançadas, como reconhecimento visual por inteligência artificial, aprendizado automático de preferências, autenticação real e sincronização entre smartphones, representam a **visão futura do produto** e ainda não estão implementadas como serviços funcionais nesta versão.
